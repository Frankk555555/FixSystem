# Campus Fix Hub (71)

ขอบเขตของโครงงาน (Project Scope)

โครงงานระบบแจ้งซ่อมออนไลน์ภายในมหาวิทยาลัย

การกำหนดขอบเขตของโครงงานนี้ จัดทำขึ้นเพื่อให้เห็นภาพรวมของระบบและหน้าที่การทำงานทั้งหมดอย่างชัดเจน โดยแบ่งขอบเขตออกเป็นด้านต่าง ๆ ดังนี้

1. ขอบเขตด้านผู้ใช้งาน (User Roles)

ระบบรองรับกลุ่มผู้ใช้งานหลักทั้งหมด 3 กลุ่ม โดยมีสิทธิ์และหน้าที่แตกต่างกันดังนี้:

1.1 ผู้ใช้งานทั่วไป (User - นักศึกษา อาจารย์ และบุคลากรทั้งหมดในมหาวิทยาลัย)

เป็นผู้ที่มีสิทธิ์ใช้งานระบบเพื่อแจ้งปัญหาชำรุดเสียหายภายในพื้นที่มหาวิทยาลัย

1.2 ช่างซ่อม (Technician - แบ่งออกเป็น 3 แผนก)

แผนกไฟฟ้า: รับผิดชอบและจัดการงานซ่อมที่เกี่ยวข้องกับระบบไฟฟ้า แสงสว่าง และเครื่องใช้ไฟฟ้า

แผนกประปา: รับผิดชอบและจัดการงานซ่อมที่เกี่ยวข้องกับระบบประปา ท่อน้ำ และสุขภัณฑ์

แผนกซ่อมสร้าง: รับผิดชอบและจัดการงานซ่อมทั่วไป โครงสร้าง อาคาร เฟอร์นิเจอร์ และงานปูน/งานไม้

1.3 ผู้ดูแลระบบ (Admin - เจ้าหน้าที่ส่วนกลาง) (แนะนำเพิ่มเติมเพื่อความสมบูรณ์ของระบบ)

มีหน้าที่ตรวจสอบข้อมูลการสมัครสมาชิก จัดการสิทธิ์การใช้งานของช่างซ่อม คัดกรองและส่งต่องานแจ้งซ่อมไปยังแผนกช่างที่ถูกต้อง และควบคุมภาพรวมของระบบ

2. ขอบเขตด้านกระบวนการทำงานของระบบ (System Functions)

ระบบมีฟังก์ชันและกระบวนการทำงานหลัก (Core Processes) แบ่งตามโมดูลดังนี้:

2.1 ระบบจัดการสมาชิกและการเข้าสู่ระบบ (User Management & Authentication)

รองรับการลงทะเบียน (Registration) สำหรับผู้ใช้งานทั่วไป โดยจัดเก็บข้อมูลสำคัญ ได้แก่:

ชื่อ-นามสกุล

เบอร์โทรศัพท์สำหรับการติดต่อกลับ

อีเมลสำหรับเข้าใช้งาน (รองรับทั้งอีเมลส่วนตัวทั่วไป เช่น Gmail, Hotmail และอีเมลของมหาวิทยาลัย)

รหัสนักศึกษา หรือ รหัสบุคลากร (เพื่อใช้ยืนยันสถานะความเป็นบุคลากรในมหาวิทยาลัยทดแทนการจำกัดประเภทอีเมล)

ระบบลงทะเบียนและจัดการข้อมูลของช่างซ่อม (แยกประเภทแผนกช่าง)

ระบบเข้าสู่ระบบ (Login) และออกจากระบบ (Logout) เพื่อความปลอดภัยของข้อมูล

2.2 ระบบรับแจ้งซ่อม (Repair Request System)

การสร้างรายการแจ้งซ่อมใหม่ (Create Request): ผู้ใช้งานสามารถสร้างรายการแจ้งซ่อมใหม่ได้สะดวก โดยระบบจะจัดการข้อมูลดังนี้:

ข้อมูลผู้แจ้งชำรุด: ดึงข้อมูลชื่อและเบอร์โทรศัพท์ของผู้ใช้งานจากระบบโปรไฟล์โดยอัตโนมัติ (ไม่ต้องกรอกซ้ำ)

ประเภทของปัญหา: เลือกแผนกช่างที่ต้องการส่งเรื่อง (ไฟฟ้า / ประปา / ซ่อมสร้าง)

ระดับความเร่งด่วน: ผู้แจ้งสามารถระบุระดับความสำคัญได้ (เช่น ทั่วไป / ด่วน / ด่วนที่สุด) เพื่อช่วยให้ช่างจัดลำดับความสำคัญของงาน

สถานที่ที่ต้องการให้เข้าซ่อม: ระบุสถานที่อย่างละเอียด โดยเลือกจากรายชื่ออาคารในมหาวิทยาลัย (เพื่อป้องกันการสะกดชื่ออาคารผิด) พร้อมช่องกรอก ชั้น, เลขห้อง หรือจุดอ้างอิงเพิ่มเติม

รายละเอียดและอาการชำรุด: กรอกคำอธิบายปัญหาหรือลักษณะอาการชำรุด

การแนบไฟล์สื่อ (Media Attachment): รองรับการถ่ายภาพใหม่จากกล้องมือถือ หรือเลือกรูปภาพ/วิดีโอสั้นจากคลังภาพ เพื่อให้ช่างเห็นภาพหน้างานจริงและเตรียมอุปกรณ์ได้ถูกต้อง

ระบบออกหมายเลขใบงาน (Job ID Generation): เมื่อกดยืนยัน ระบบจะสร้างหมายเลขใบสั่งซ่อม (Ticket ID) อัตโนมัติ เพื่อใช้ในการติดตามและอ้างอิงการสนทนา

ระบบคัดกรองและจ่ายงานอัตโนมัติ (Auto-Routing): ระบบจะส่งข้อมูลการแจ้งซ่อมเข้าสู่กล่องงาน (Job Queue) ของแผนกช่างที่เกี่ยวข้องโดยตรงและทันทีตามที่ผู้ใช้เลือก

2.3 ระบบนัดหมายและปฏิทินงานช่าง (Scheduling & Calendar System)

ฝั่งช่างซ่อม: สามารถระบุวันและเวลาที่สะดวก เพื่อลงนัดหมายในปฏิทินงานได้

ฝั่งผู้ใช้งาน: สามารถเลือกวันและเวลาจากปฏิทินนัดหมายที่ช่างว่าง เพื่อจองคิวให้ช่างเข้ามาดำเนินการซ่อมแซม

ระบบแสดงผลปฏิทิน (Calendar View) เพื่อแสดงรายการนัดหมายทั้งหมดของทั้งสองฝ่าย ป้องกันการนัดซ้อน

2.4 ระบบแชทสื่อสาร (Chat Communication System)

มีช่องทางแชท (Chat Room) แบบตัวต่อตัวระหว่างผู้ใช้งาน (เจ้าของเรื่องที่แจ้งซ่อม) และช่างซ่อมที่รับผิดชอบงานนั้น ๆ

ฟังก์ชันการทำงานในช่องแชท:

การส่งข้อความ: ใช้สำหรับพูดคุย สอบถามรายละเอียดเพิ่มเติม นัดแนะสถานที่ หรือแจ้งข้อมูลเร่งด่วน โดยไม่ต้องเปิดเผยเบอร์โทรศัพท์ส่วนตัวหากไม่จำเป็น

การส่งรูปภาพในแชท: รองรับการถ่ายภาพหรือส่งรูปภาพผ่านห้องแชท เพื่อให้ช่างและผู้แจ้งใช้ส่งรูปอุปกรณ์ที่ต้องเตรียม หรือส่งรูปหน้างานปัจจุบันเพิ่มเติมได้ทันที

ระบบประวัติการสนทนา: จัดเก็บและแยกห้องแชทตามหมายเลขใบสั่งซ่อม (Job ID) เพื่อป้องกันการสับสนของข้อมูลและใช้อ้างอิงการทำงานย้อนหลังได้

2.5 ระบบติดตามและแจ้งเตือนสถานะการซ่อม (Status Tracking & Notification)

ระบบรองรับการอัปเดตสถานะของงานซ่อมแซม โดยแบ่งสถานะหลักดังนี้:

รอดำเนินการ (Pending): งานถูกส่งเข้าระบบเรียบร้อยแล้ว

รับเรื่องแล้ว/กำลังจัดหาช่าง (Assigned): ระบบหรือหัวหน้าช่างมอบหมายงานให้ช่างเฉพาะทางแล้ว

นัดหมายสำเร็จ (Scheduled): ช่างและผู้แจ้งทำการเลือกวันเวลาเข้าซ่อมเรียบร้อย

กำลังดำเนินการ (In Progress): ช่างกำลังทำการซ่อมแซม ณ สถานที่จริง

เสร็จสิ้น (Completed): ช่างทำการซ่อมเรียบร้อย และผู้ใช้กดยืนยันการปิดงาน

ผู้ใช้งานสามารถเข้ามาหน้าแดชบอร์ดเพื่อตรวจสอบสถานะปัจจุบันของงานแจ้งซ่อมทั้งหมดของตนเองได้ตลอดเวลา

2.6 ระบบออกรายงานทั่วไป (Reporting & Dashboard System)

ระบบสามารถสรุปและแสดงผลรายงานในรูปแบบตารางหรือกราฟอย่างง่าย เช่น:

รายงานสถิติจำนวนการแจ้งซ่อมจำแนกตามแผนก (ไฟฟ้า / ประปา / ซ่อมสร้าง) เพื่อดูว่าส่วนใดชำรุดบ่อยที่สุด

รายงานระยะเวลาเฉลี่ยในการปิดงานของแต่ละแผนก

รายงานสรุปสถานะงานแจ้งซ่อมในแต่ละเดือน (เช่น เสร็จสิ้นกี่งาน, คงค้างกี่งาน) เพื่อให้ผู้บริหารหรือผู้ดูแลระบบนำไปใช้วางแผนปรับปรุงต่อไป
